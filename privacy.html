隐私政策

最后更新：2026-09-29

这份政策说明 rillo.dev 会接触哪些数据、如何处理。本站目前是静态介绍页：没有账号、没有表单、没有埋点，也不在你的浏览器里写入任何本站数据。

1. 本站在你的设备上做什么

本站不使用 cookie、localStorage 或会话存储，不做访问统计与用户画像，页面上也没有输入处。动画全部由 CSS 实现，不加载统计或广告脚本。

2. 托管与访问日志

本站托管在 GitHub Pages。为提供与保护服务，GitHub 可能处理你的 IP 地址、User-Agent、请求时间等访问日志，rillo 项目不另行留存这些日志。相关处理适用 GitHub 隐私声明。

3. 字体请求

页面从 Google Fonts 加载字体，你的浏览器会直接请求 fonts.googleapis.com 与 fonts.gstatic.com（Google 会看到你的 IP 地址）。屏蔽这两个域后，页面仍会用回退字体正常显示。

4. 第三方链接

本站可能链接到 GitHub 等第三方站点，这些站点由其自身的隐私政策约束，我们不控制也不对其负责。

5. 政策变更

政策调整时会修改本页顶部的「最后更新」日期；涉及数据处理的重大变化会在本页显著说明。

6. 联系方式

对隐私处理有疑问，请在 rillo-site 仓库 提交 issue。
